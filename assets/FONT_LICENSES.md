# Bundled font licenses

The release bundles the following unmodified fonts:

- `JetBrainsMonoNerdFontMono-Regular.ttf`: JetBrains Mono / Nerd Fonts,
  licensed under the SIL Open Font License 1.1.
- `NotoSansSC-VF.ttf`: Noto Sans SC, licensed under the SIL Open Font License
  1.1.

Copyright information is retained in each font's metadata. The common license
text is included in [`OFL-1.1.txt`](./OFL-1.1.txt).

Upstream projects:

- https://github.com/JetBrains/JetBrainsMono
- https://github.com/notofonts/noto-cjk
