# Hardware Workbench v1.0.0

Hardware Workbench 的首个正式版本现已发布。这是一款基于 Rust + egui 的桌面串口调试工作台，面向日常硬件联调、串口数据观察、录制回放以及通过 Lua 插件扩展设备工作流。

## 主要功能

- 串口连接与数据收发，支持文本/HEX、时间戳、搜索过滤和日志导出。
- 灵活的发送器，支持文本/HEX、换行配置、周期发送和文件发送扩展。
- JSONL 数据录制与回放，支持步进、变速和回放阶段重新解析。
- 可自由停靠的工作区、深浅主题、布局持久化和可自定义快捷键。
- Lua 插件运行时，支持生命周期、权限、命令、任务、配置以及图表、仪表和表单等动态面板。
- 内置插件市场，可直接发现、安装、启用、停用和卸载插件。

## 1.0.0 重点变化

- 将桌面端统一为 Rust + egui 实现，清理 Flutter 与小窗模式遗留。
- 将插件源码、官方市场索引和版本化产物合并到同一仓库维护。
- 重构插件管理界面，在宽屏和窄屏下使用更紧凑、稳定的响应式布局。
- 提升文字、选中态和次要操作的对比度，减少界面中的冗余提示。
- 修复接收区与日志区的自动跟随：向上滚动即可暂停，恢复动作也更易理解。
- 支持在拖选文本或跨行选择时继续使用滚轮滚动。
- 修复设置导航、工具栏按钮和插件统计切换时的布局抖动。

## 下载

本版本提供 Windows x64 构建：

- `HardwareWorkbenchSetup.exe`：安装版，推荐普通用户使用。
- `hardware-workbench-app.zip`：便携版，解压后直接运行。
- `SHA256SUMS.txt`：以上发布文件的 SHA-256 校验值。

下载完成后可以在 PowerShell 中校验文件：

```powershell
Get-FileHash .\HardwareWorkbenchSetup.exe -Algorithm SHA256
Get-FileHash .\hardware-workbench-app.zip -Algorithm SHA256
```

计算结果应与 `SHA256SUMS.txt` 一致。

便携包默认不包含个人脚本、测试脚本或 G-code Sender；需要的插件可在插件市场中安装。

## 从旧版本升级

- 建议升级前备份 `%APPDATA%\HardwareWorkbench\workspace.json` 和 `plugin-config` 目录。
- 旧版工作区布局、主题和插件配置会在首次启动时自动迁移。
- 应用内更新使用便携包完成替换；也可以下载安装器覆盖安装。

## 使用提示

- 接收区自动跟随开启时，向上滚动会暂停跟随；点击“恢复跟随”回到最新数据。
- 插件所需权限会显示在插件卡片中，启用前可以先确认权限范围。
- 所有快捷键均可在设置中自行调整。
