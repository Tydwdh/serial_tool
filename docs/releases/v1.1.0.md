# Hardware Workbench v1.1.0

Hardware Workbench v1.1.0 带来终端性能优化、应用层架构整理，以及首个 Ubuntu `.deb` 发布包。

## 重点变化

- 重构终端流存储，虚拟化行布局并延迟生成终端行，大量接收数据时减少界面开销。
- 建立 UI 无关的 application core 和 DTO 驱动的界面边界，降低前端与业务实现的耦合。
- 支持 Ubuntu 22.04+ x86_64 `.deb` 安装包。
- Ubuntu 安装后从应用菜单直接运行，程序、插件、主题和录制文件使用普通用户目录。
- 串口权限不足时提示加入 `dialout` 用户组；不需要、也不建议使用 `sudo` 启动应用。

## 下载

Windows x64：

- `HardwareWorkbenchSetup.exe`：安装版。
- `hardware-workbench-app.zip`：便携版。
- `SHA256SUMS.txt`：Windows 发布文件校验值。

Ubuntu 22.04+ x86_64：

- `hardware-workbench_1.1.0_amd64.deb`：系统安装包。
- `SHA256SUMS-linux.txt`：Linux 安装包校验值。

## Ubuntu 安装与运行

安装阶段需要一次系统权限：

```bash
sudo apt install ./hardware-workbench_1.1.0_amd64.deb
```

安装完成后，可以点击应用菜单中的 `Hardware Workbench`，或执行：

```bash
hardware-workbench-app
```

以上运行方式都使用当前普通用户。不要执行 `sudo hardware-workbench-app`。

如果打开 `/dev/ttyUSB0` 或 `/dev/ttyACM0` 时出现 `Permission denied`：

```bash
sudo usermod -aG dialout $USER
```

注销并重新登录后即可再次打开串口。Ubuntu 版本通过新的 `.deb` 包升级，不使用 Windows 便携版的应用内更新入口。

## Windows 升级

Windows 用户可以覆盖安装新的安装器，或解压新的便携包。升级前建议备份
`%APPDATA%\HardwareWorkbench\workspace.json` 和插件配置目录。
