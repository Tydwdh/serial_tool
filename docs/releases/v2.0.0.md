# Hardware Workbench 2.0.0

## 重点变化

- **移除 Web 版（wasm32 / 在线模式）**：删除 wasm 目标、浏览器组合根、web 平台适配、omniLua 引擎与差分测试、Web CI 与 GitHub Pages 发布、Trunk 工程与 web 文档。
- **收口为单一 native 组合根**：`AppRuntime` trait、`AppCapabilities`/`Capability` 门控与面板能力过滤删除；UI 直接持有 `Workbench`。`tool-plugin-api` 只保留 native 插件契约。
- **插件运行时收口**：只保留 `tool-lua-host`（mlua）；`tool-plugin-runtime` 与 `omnilua` 依赖删除。
- **CI 与发布**：移除 wasm 作业与 Pages 工作流；Windows 测试、Ubuntu `.deb` 与 GitHub Release 保持。

## 在线版终止

在线版止于 `v1.3.2`。仓库的 `v1.3.2` tag 仍可检出；GitHub Pages 已停用。桌面版下载：

<https://github.com/Tydwdh/serial_tool/releases>

## 已知限制

- macOS 不受支持。
- Linux 自动更新仍未启用（见 [known-gaps.md](../known-gaps.md)）。
- 插件市场与模板插件不变；安装路径不受影响。
