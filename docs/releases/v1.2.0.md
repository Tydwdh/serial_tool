# Hardware Workbench v1.2.0

Hardware Workbench v1.2.0 提供可直接访问的浏览器在线模式，并继续统一 Native 与 Web 的工作台
界面、Application 边界和串口能力。

## 在线模式

打开：<https://tydwdh.github.io/serial_tool/>

在线版使用最新版 Chrome 或 Edge 即可运行。连接本机串口时，点击“添加设备”，在浏览器弹窗中
选择设备并授权；浏览器不会在页面打开时自动弹出权限请求。在线版支持 Web Serial、网络串口、
终端、日志、图表、发送器、主题、设置和 Lua 插件的浏览器等价能力。

## 重点变化

- Native 与 Web 共用 egui、Dock、Terminal、Log、Chart、发送器、设置和插件设置 UI。
- 接入 Web Serial 的已授权设备刷新、用户主动授权、连接、断开、TEXT/HEX 收发和 DTR/RTS。
- 增加网络串口，并统一 Native/Web 的异步串口任务、状态事件和 Application 命令边界。
- Web 端支持 Lua 插件命令、动态面板、发送器工具栏按钮、市场索引和浏览器文件选择。
- 恢复并统一默认 Dock 布局，修复发送器窄宽度下按钮换行、端口名称显示和分组状态显示问题。
- 修复 WASM 下系统时间接口未实现导致的页面 panic。
- 修复 Native 手动关闭后自动重连、串口 worker 重连竞态，以及 Web 插件按钮点击无效问题。
- 增加 Web 性能诊断、WASM release 构建和 GitHub Pages 发布检查。

## 桌面版下载

Windows x64：

- `HardwareWorkbenchSetup.exe`：安装版。
- `hardware-workbench-app.zip`：便携版。
- `SHA256SUMS.txt`：Windows 发布文件校验值。

Ubuntu 22.04+ x86_64：

- `hardware-workbench_1.2.0_amd64.deb`：系统安装包。
- `SHA256SUMS-linux.txt`：Linux 安装包校验值。

## 注意事项

- Web Serial 需要 Chrome/Edge，并受浏览器、HTTPS/localhost、用户手势和设备驱动限制。
- 在线版使用浏览器存储和下载，不具备桌面端原生文件路径和原地自动更新能力。
- 本地 Web 开发请使用 `trunk serve --release`；不带 `--release` 会运行 Debug WASM，性能会明显下降。
