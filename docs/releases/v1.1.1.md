# Hardware Workbench v1.1.1

Hardware Workbench v1.1.1 是面向 v1.1.0 用户的修复与体验改进版本。

## 重点变化

- 稳定终端虚拟列表滚动和增量布局更新。
- 仅在 transport 确认端口真正打开后显示连接成功提示；连接超时会明确提示失败。
- 优化无配置文件时的默认工作区布局，启动后默认显示终端。
- Dock 拖拽时关闭容易误触发的上下拆分目标，保留左右拆分和标签合并。
- 收紧通知、配置路径和设备面板的布局与显示时长。
- 修复 Ubuntu `.deb` 打包时应用命令符号链接目录缺失的问题。

## 下载

Windows x64：

- `HardwareWorkbenchSetup.exe`：安装版。
- `hardware-workbench-app.zip`：便携版。
- `SHA256SUMS.txt`：Windows 发布文件校验值。

Ubuntu 22.04+ x86_64：

- `hardware-workbench_1.1.1_amd64.deb`：系统安装包。
- `SHA256SUMS-linux.txt`：Linux 安装包校验值。

## Ubuntu 安装与运行

安装阶段需要一次系统权限：

```bash
sudo apt install ./hardware-workbench_1.1.1_amd64.deb
```

安装完成后，可以点击应用菜单中的 `Hardware Workbench`，或执行：

```bash
hardware-workbench-app
```

以上运行方式都使用当前普通用户。不要执行 `sudo hardware-workbench-app`。

如果打开 `/dev/ttyUSB0` 或 `/dev/ttyACM0` 时出现 `Permission denied`：

```bash
sudo usermod -aG dialout $USER
```

注销并重新登录后即可再次打开串口。
