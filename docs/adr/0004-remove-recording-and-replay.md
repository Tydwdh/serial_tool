# 删除录制/回放、命令面板与全局快捷键，收敛为单端口监视工作台

日期：2026-10-30

## 决策

- 删除 `tool-recorder` 与录制/回放相关的应用命令、面板、Lua 分析器、插件清单字段、文档和测试。
  历史 JSONL 不再由本应用生成或播放。
- 删除命令面板、`CommandRegistry`、全局快捷键映射及设置中的快捷键分类。界面只保留面板内的局部控件；
  不再提供可配置的全局键位。
- 同一窗口同一时刻只保持一个活动连接。连接新端口时先关闭旧端口；终端在活动端口切换时清空。
  多端口并行监控改为启动多个应用实例。
- 默认布局改为监视优先：中间为接收终端与日志，底部为发送器（28%），右侧设备抽屉默认隐藏。
  旧布局通过 `PanelManager.layout_version` 迁移到新默认布局。
- 移除内置图表注册；保留 `ChartPanel` 供 Lua 插件动态面板使用。
- 不提升版本号，不发布新包。

## 原因

- 录制/回放、命令面板与全局快捷键与当前「串口监视器」定位不匹配，且长期存在无生产调用者的状态、
  面板与文档分支，维护成本高于使用价值。
- 多端口并行连接带来的终端归属、发送目标和状态同步问题，使单窗口行为难以预测；单端口 + 多实例
  的边界更简单，也保留了并行监控能力。

## 后果

- `workspace.json` 中旧布局、快捷键、录制路径等字段不再产生效果；未知字段被忽略。
- 依赖录制/回放的插件清单字段与 Lua API 不再被接受；模板与生成文档已同步删除。
- 终端、日志、发送器、设备列表、插件（含动态图表）与网络串口保持可用。
- 后续若恢复录制能力，应作为独立 crate 与新命令重新引入，而不是恢复旧管理器的隐式状态。
