# 接收区：显示时间/端口复选框 + 列间距优化

**日期**: 2026-06-22
**状态**: 已确认

## 背景

接收区（TerminalPanel）全局视图中，每行固定显示时间戳、端口名、方向标签和内容。用户希望在查看连贯数据时能隐藏时间戳和端口信息，同时端口列宽度过大（64px），COM 口最多 5 字符（如 `COM99`），间距浪费空间。

## 设计

### 1. 新增两个独立复选框

在 `TerminalPanel` 结构体中新增：

```rust
show_timestamp: bool,  // 默认 true
show_port: bool,       // 默认 true
```

**位置**：全局视图 `ui()` 的搜索/端口过滤行，和"搜索"、"端口"、"清除筛选"并排。

**行为**：
- `show_timestamp`：控制时间戳列的显示/隐藏
- `show_port`：控制端口列的显示/隐藏
- 两个复选框独立工作，可分别控制
- 仅影响全局视图（`ui()` 方法），单端口视图（`port_ui()`）也加上"显示时间"，但不加"显示端口"（单端口视图端口名已在工具栏）

**导出行为**：CSV/JSONL 导出跟随复选框状态 — 隐藏的列不导出。

### 2. 缩小端口列宽度

`PORT_COL_WIDTH` 从 `64.0` 缩小到 `52.0`。

5 字符等宽字体约 42-48px，52px 留有安全余量，避免截断。

### 3. 缩小列间距

`COL_GAP` 从 `4.0` 缩小到 `3.0`。

## 影响范围

- [crates/panels/src/terminal.rs](crates/panels/src/terminal.rs)：
  - 新增 `show_timestamp`、`show_port` 字段
  - 修改 `PORT_COL_WIDTH`、`COL_GAP` 常量
  - `ui()` 方法：搜索行添加两个复选框
  - `port_ui()` 方法：工具栏添加"显示时间"复选框
  - `show_entry_multiline()` 函数：根据字段条件跳过时间戳/端口列的渲染
  - `export_visible_csv()` / `export_visible_jsonl()`：根据字段条件跳过对应列
  - `clear()` 方法：重置两个字段为默认值

## 不涉及

- 日志面板、发送面板、图表等其他面板
- 单端口视图不添加"显示端口"复选框（无意义）
- 详情弹窗（始终显示完整信息）
