# 接收区：文本选择复制 + 原始文本显示

**日期**: 2026-06-23
**状态**: 已确认

## 背景

1. 接收区当前使用 `painter.text()` 逐行绘制，用户无法像文本编辑器一样拖选复制文字。多条数据时复制操作很麻烦。
2. 需要新增"显示原始文本"选项，勾选后显示包含 `\n`、`\r`、`\t` 等控制字符可视化表示的原始文本。

## 设计

### 1. 内容区域改为只读 TextEdit

将 `show_entry_multiline()` 的内容渲染从 `painter.text()` 改为只读 `TextEdit::multiline()`。

**实现方式：**
- 将所有可见行的数据文本拼接成一个多行字符串，每条数据占一行（即使数据本身无 `\n`）
- 时间戳、端口、方向标签保留在左侧用 `painter.text()` 绘制（作为不可选的"边框"）
- 整个内容区域是一个大的只读 `TextEdit`，天然支持鼠标拖选、Ctrl+A 全选、Ctrl+C 复制

**牺牲的功能（可接受）：**
- 行选择高亮（蓝色背景）
- 双击查看详情（可通过右键菜单进入）
- 自定义右键菜单（TextEdit 自带右键菜单：复制/全选等）

**保留的功能：**
- 时间戳、端口、方向标签的颜色样式（painter 绘制在左侧）
- RX/TX 复选框过滤
- 搜索过滤
- 自动滚动
- 书签
- HEX 模式切换
- 详情弹窗（通过其他方式进入）

### 2. 新增"原始复选框

在 HEX 复选框旁边新增"原始"复选框（`show_raw: bool`，默认 `false`）。

- 勾选后内容区显示 `raw_text`（保留 `\n`、`\r`、`\t` 等控制字符原样）
- 不勾选时，显示 `display_text`（当前行为：`\r` 跳过、其他控制字符变中间点）
- 影响接收区主视图详情弹窗
- 详情弹窗中"原始内容"区域改为显示真正的原始文本（控制字符可视化）

### 3. 详情弹窗入口

由于双击被 TextEdit 吞掉，详情弹窗入口改为：
- 右键菜单（TextEdit 自带）中可以通过"复制"等方式获取内容
- 保留工具栏的"放大查看"按钮（⛶），点击后打开当前选中端口的详情

## 影响范围

- [crates/panels/src/terminal.rs](crates/panels/src/terminal.rs)：
  - `TerminalPanel` 新增 `show_raw: bool` 字段（默认 `false`）
  - `show_entry_multiline()` 重构：painter 绘制时间/端口/方向 + TextEdit 渲染内容
  - `ui()` 和 `port_ui()` 工具栏添加"原始"复选框
  - `clear()` 重置 `show_raw = false`
  - 详情弹窗"原始内容"改为显示真正的原始文本

## 不涉及

- 日志面板、发送面板、图表等其他面板
- 串口通信层
- 导出逻辑（CSV/JSONL 导出保持现有行为）
